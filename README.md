## 💻 How to Run Locally

### Option 1: Double-Click
You can directly open `index.html` in any web browser (Chrome, Edge, Firefox, Brave).

### Option 2: Run with Node.js Preview Server
Open terminal in this directory and run:
```bash
node server.js
```
Then visit:
```
http://localhost:5000
```

## 🌐 Deploy to GitHub Pages or Vercel

### Deploy to GitHub Pages (Free)
1. Initialize git in this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   ```
2. Create a new repository on GitHub (e.g. `bhanu-portfolio` or `bhanuyadav.github.io`).
3. Push your repository:
   ```bash
   git remote add origin https://github.com/bhanuyadav/bhanu-portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub repository settings -> **Pages** -> Select `main` branch `/ (root)` and click Save.

### Deploy to Vercel (1-Click)
1. Run `npx vercel` or import the GitHub repository in the [Vercel Dashboard](https://vercel.com).
